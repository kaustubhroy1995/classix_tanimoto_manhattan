# Experiments

Use the curated revision notebooks:

- `experiment_1/01_synthetic_benchmarks.ipynb`: synthetic scaling, full reruns and plots.
- `experiment_1/02_molecular_benchmarks.ipynb`: Greg Landrum's chemical fingerprints, five fixed configurations, runtime/ARI/AMI/silhouette/CHI_T.
- `experiment_1/03_radius_sensitivity.ipynb`: 10,000 binary vectors, 1,024 dimensions, six radii and five methods, ARI/AMI.
- `experiment_2/01_euclidean_manhattan_comparison.ipynb`: twenty standardized original-feature datasets and the complete CLASSIX/DBSCAN/OPTICS Euclidean/Manhattan study.

See [REPRODUCIBILITY.md](REPRODUCIBILITY.md) for the executed settings, timing scope and result-file layout. The root README describes Python, native build and notebook setup. Run the small pilot/check modes before the full computations. Full binary DBSCAN and Taylor-Butina runs can be long and memory intensive.

Generated data, native builds, environment files and run records are excluded from Git. Supplied PDFs are paper plot references; the Landrum PNG is a preview read before the molecular notebook runs. Numerical outputs are generated by the notebooks.

The six notebooks directly in this directory are earlier studies. `classix_t_prob.ipynb` remains the producer for the probability-analysis figures; the other historical notebooks are retained for context and are not the updated benchmark entry points.
