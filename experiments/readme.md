# Experiments

- `experiment_1/01_synthetic_benchmarks.ipynb`: synthetic scaling comparisons.
- `experiment_1/02_molecular_benchmarks.ipynb`: Greg Landrum chemical data.
- `experiment_1/03_radius_sensitivity.ipynb`: radius sensitivity on 10,000 points.
- `experiment_2/01_euclidean_manhattan_comparison.ipynb`: twenty numeric datasets.
- `classix_t_prob.ipynb`: search-bound probabilities.

Each notebook contains its executable experiment code. Install the dependencies described in the root README, then run the cells in order.
